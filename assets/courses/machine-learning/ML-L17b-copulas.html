Lecture 14 estimated densities and Lecture 17a built them from mixtures. Both treated a multivariate distribution as one object. This lecture splits it in two. Every continuous joint distribution can be written as its one-dimensional margins, which say how each variable behaves on its own, glued together by a copula, which says how they move together and nothing else. The split is useful in practice. Margins are easy to estimate one at a time, even nonparametrically; dependence is where models go wrong, and a copula lets us model it separately, test it, and see where it lives: near the middle of the distribution, or in the tails, where joint crashes and joint floods happen.

By the end you should be able to state and use Sklar's theorem and the probability integral transform; compute Kendall's tau, Spearman's rho and tail dependence from a copula; choose between Gaussian, \(t\) and Archimedean copulas and fit them by maximum pseudo-likelihood on ranks; and use copulas in machine learning to generate synthetic tabular data and to estimate graphical models that are robust to unknown monotone transformations of the data.

1 — Dependence beyond correlation

Pearson's correlation measures linear association. It is the right summary for a bivariate normal distribution, where it determines the whole dependence structure, and a poor one almost everywhere else. Three facts make this concrete. It changes when one variable is put through an increasing transformation (a change of units from returns to cubed returns, or from income to log income), although the "amount of dependence" has not changed. It can be zero for variables that are perfectly dependent, such as \(X\) and \(X^2\) for a symmetric \(X\). And very different joint distributions share the same correlation, which matters most when the difference is in the tails.

The last point is the subject of this lecture's first experiment. We draw from five joint distributions that all have standard normal margins and all have the same Kendall rank correlation (Definition 17.8), and ask how often the two variables are extreme together.

    if fam == 'Gaussian':

    if fam.startswith('t'):

        q = (x ** 2 + y ** 2 - 2 * th * x * y) / (1 - th ** 2)

        return lj - stats.t.logpdf(x, nu) - stats.t.logpdf(y, nu)
    if fam == 'Clayton':
        return np.log1p(th) - (th + 1) * (np.log(u) + np.log(v)) - (2 + 1 / th) * np.log(u ** -th + v ** -th - 1)
    if fam == 'Gumbel':

        return -A1 - np.log(u * v) + (th - 1) * np.log(a * b) + (1 / th - 2) * np.log(A) + np.log(A1 + th - 1)
    if fam == 'Frank':
        e = -np.expm1(-th)

def sample(fam, th, n, g):                                      # n draws (U, V) from the copula
    u, w = g.random(n), g.random(n)
    if fam == 'Gaussian':
        z = g.multivariate_normal([0, 0], [[1, th], [th, 1]], n); return Phi(z[:, 0]), Phi(z[:, 1])
    if fam.startswith('t'):
        z = g.multivariate_normal([0, 0], [[1, th], [th, 1]], n) / np.sqrt(g.chisquare(4, n) / 4)[:, None]
        return stats.t.cdf(z[:, 0], 4), stats.t.cdf(z[:, 1], 4)
    if fam == 'Clayton':                                         # invert the conditional distribution C(v | u)
        return u, (u ** -th * (w ** (-th / (1 + th)) - 1) + 1) ** (-1 / th)
    if fam == 'Frank':
        return u, -np.log1p(w * -np.expm1(-th) / (w * (np.exp(-th * u) - 1) - np.exp(-th * u))) / th
    if fam == 'Gumbel':                                          # Marshall-Olkin: a positive stable frailty S, then exp(-(E/S)^(1/theta))
        al = 1 / th; U, E = np.pi * g.random(n), g.exponential(size=n)
        S = np.sin(al * U) / np.sin(U) ** (1 / al) * (np.sin((1 - al) * U) / E) ** ((1 - al) / al)
        return tuple(np.exp(-(g.exponential(size=n) / S) ** al) for _ in range(2))

    lo, hi = FAM[fam]['bounds']; return optimize.brentq(lambda t: FAM[fam]['tau'](t) - tau, lo, hi)

2 — Sklar's theorem: separating margins from dependence

The construction rests on one transformation. Applying a variable's own distribution function to it produces a uniform variable, whatever the distribution was.

theorem 17.6 — the probability integral transform

Let \(X\) have a continuous distribution function \(F\). Then \(F(X)\) is uniformly distributed on \((0,1)\). Conversely, if \(U\) is uniform on \((0,1)\) and

$$F^{-}(u)=\inf\{x:F(x)\ge u\}$$

is the generalised inverse of any distribution function \(F\), then \(F^{-}(U)\) has distribution function \(F\).

For the converse, \(F^{-}(u)\le x\) holds exactly when \(u\le F(x)\), because \(F\) is non-decreasing and right-continuous. So

$$P\big(F^{-}(U)\le x\big)=P\big(U\le F(x)\big)=F(x).$$

For the first part, take \(u\in(0,1)\). By continuity there is an \(x\) with \(F(x)=u\), and \(F(X)\le u\) holds exactly when \(X\le F^{-}(u)\) up to an event of probability zero (where \(F\) is flat). Hence

$$P\big(F(X)\le u\big)=P\big(X\le F^{-}(u)\big)=F\big(F^{-}(u)\big)=u.\qquad\square$$

The converse is how computers sample from any distribution with a known quantile function, and it is how we shall put new margins on a copula.

definition 17.7 — copula

A \(d\)-dimensional copula is the distribution function of a random vector \((U_1,\dots,U_d)\) whose components are each uniformly distributed on \((0,1)\):

$$C(u_1,\dots,u_d)=P(U_1\le u_1,\dots,U_d\le u_d).$$

Three bivariate copulas are landmarks: the independence copula \(\Pi(u,v)=uv\); the comonotone copula \(M(u,v)=\min(u,v)\), the copula of \((U,U)\); and the countermonotone copula \(W(u,v)=\max(u+v-1,0)\), the copula of \((U,1-U)\). When \(C\) has a density, we write it \(c(u,v)=\partial^2C/\partial u\,\partial v\).

theorem 17.7 — Sklar's theorem (Sklar, 1959)

Let \(H\) be the joint distribution function of \((X_1,\dots,X_d)\), with margins \(F_1,\dots,F_d\). Then there is a copula \(C\) such that, for all \(x\),

$$H(x_1,\dots,x_d)=C\big(F_1(x_1),\dots,F_d(x_d)\big).$$

If the margins are continuous, \(C\) is unique: it is the distribution function of \(\big(F_1(X_1),\dots,F_d(X_d)\big)\). Conversely, for any copula \(C\) and any distribution functions \(F_1,\dots,F_d\), the formula defines a joint distribution with those margins. With densities, the joint density factorises into a copula part and a margin part:

$$h(x_1,\dots,x_d)=c\big(F_1(x_1),\dots,F_d(x_d)\big)\prod_{j=1}^df_j(x_j).$$

Let \(U_j=F_j(X_j)\). By Theorem 17.6 each \(U_j\) is uniform, so the distribution function \(C\) of \((U_1,\dots,U_d)\) is a copula. Because \(F_j\) is continuous and non-decreasing, \(X_j\le x_j\) holds exactly when \(F_j(X_j)\le F_j(x_j)\), up to an event of probability zero. Therefore

$$H(x)=P\big(F_1(X_1)\le F_1(x_1),\dots,F_d(X_d)\le F_d(x_d)\big)=C\big(F_1(x_1),\dots,F_d(x_d)\big).$$

Any other copula with this property agrees with \(C\) on \(\operatorname{Ran}F_1\times\dots\times\operatorname{Ran}F_d=(0,1)^d\), so \(C\) is unique. For the converse, let \((U_1,\dots,U_d)\sim C\) and \(X_j=F_j^{-}(U_j)\). By Theorem 17.6 each \(X_j\) has distribution \(F_j\), and, using \(F_j^-(u)\le x\iff u\le F_j(x)\),

$$P(X_1\le x_1,\dots,X_d\le x_d)=P\big(U_1\le F_1(x_1),\dots,U_d\le F_d(x_d)\big)=C\big(F_1(x_1),\dots,F_d(x_d)\big).$$

The density formula follows by differentiating once in each argument and using the chain rule. \(\square\)

The density formula is why the split pays off in estimation: the log-likelihood of a sample is the sum of one term for each margin and one term for the copula, so they can be fitted separately. Two simple facts complete the picture. Every copula lies between the two extreme cases, and the copula does not see changes of units.

theorem 17.8 — the Fréchet–Hoeffding bounds

Every bivariate copula satisfies

$$W(u,v)=\max(u+v-1,0)\;\le\;C(u,v)\;\le\;\min(u,v)=M(u,v).$$

The upper bound is attained when \(V\) is an increasing function of \(U\), the lower when it is a decreasing one.

\(C(u,v)=P(U\le u,V\le v)\) is at most \(P(U\le u)=u\) and at most \(P(V\le v)=v\). For the lower bound,

$$C(u,v)=P(U\le u)+P(V\le v)-P(U\le u\text{ or }V\le v)\ge u+v-1,$$

and \(C\ge0\). The copula of \((U,U)\) is \(P(U\le\min(u,v))=\min(u,v)\); that of \((U,1-U)\) is \(P(1-v\le U\le u)=\max(u+v-1,0)\). \(\square\)

proposition 17.9 — copulas ignore changes of scale

If \(g_1,\dots,g_d\) are strictly increasing, then \(\big(g_1(X_1),\dots,g_d(X_d)\big)\) has the same copula as \((X_1,\dots,X_d)\). In particular, anything computed from ranks alone is a property of the copula.

The distribution function of \(g_j(X_j)\) is \(F_j\circ g_j^{-1}\), and applying it to \(g_j(X_j)\) gives back \(F_j(X_j)\). So the vectors of probability integral transforms, whose distribution is the copula by Theorem 17.7, are identical. Ranks are preserved by increasing maps, so rank statistics are functions of the copula. \(\square\)

In data we do not know the margins, but we have a natural estimate of \(F_j(X_{ij})\): the rank of observation \(i\) among the \(n\) values of variable \(j\), scaled into the unit interval. The values

$$\hat U_{ij}=\frac{\operatorname{rank}(X_{ij})}{n+1}$$

are called pseudo-observations; dividing by \(n+1\) rather than \(n\) keeps them strictly inside \((0,1)\), where copula densities are finite. Here they are on real data.

spot check 17.5

You fit a copula to the pseudo-observations of two variables, then discover that one variable was recorded in logarithms. What do you need to refit?

  • The copula.
  • Only that variable's margin, if you use one; the copula is unchanged.
  • Both the margin and the copula.
What does a strictly increasing transformation do to the ranks (Proposition 17.9)?
The log is strictly increasing, so the ranks of the variable do not change, and neither do the pseudo-observations or anything fitted to them. Only a model of that variable's own distribution needs refitting.

3 — Measuring dependence with copulas: ranks and tails

If dependence is the copula, a measure of dependence should be a property of the copula alone. Pearson's correlation is not (it changed when we cubed a series), but two older rank correlations are.

definition 17.8 — Kendall's tau and Spearman's rho

Let \((X_1,Y_1)\) and \((X_2,Y_2)\) be independent copies of \((X,Y)\). The pair is concordant if \((X_1-X_2)(Y_1-Y_2)>0\) and discordant if the product is negative. Kendall's tau is

$$\tau=P\big[(X_1-X_2)(Y_1-Y_2)\gt0\big]-P\big[(X_1-X_2)(Y_1-Y_2)\lt0\big],$$

and Spearman's rho is the Pearson correlation of the probability integral transforms,

$$\rho_S=\operatorname{corr}\big(F(X),G(Y)\big).$$

Their sample versions use the observed pairs and the ranks (Kendall, 1938; Spearman, 1904). Both lie in \([-1,1]\), equal \(1\) for the copula \(M\), \(-1\) for \(W\) and \(0\) for \(\Pi\).

proposition 17.10 — rank correlations are functionals of the copula

For continuous \((X,Y)\) with copula \(C\),

$$\tau=4\int_0^1\!\!\int_0^1C(u,v)\,dC(u,v)-1,\qquad\rho_S=12\int_0^1\!\!\int_0^1\big(C(u,v)-uv\big)\,du\,dv.$$

For the Gaussian copula with correlation parameter \(r\) (the copula of a bivariate normal with correlation \(r\)),

$$\tau=\frac2\pi\arcsin r,\qquad\rho_S=\frac6\pi\arcsin\frac r2.$$

By Proposition 17.9 we may work with \((U,V)=(F(X),G(Y))\). Concordance has probability \(2P(U_2\lt U_1,V_2\lt V_1)=2\,\mathbb E[C(U_1,V_1)]\), and discordance has probability one minus that, so \(\tau=4\,\mathbb E[C(U,V)]-1\), which is the first formula. For Spearman's rho, \(\operatorname{var}U=\operatorname{var}V=1/12\), and Hoeffding's covariance identity gives

$$\operatorname{cov}(U,V)=\int_0^1\!\!\int_0^1\big(C(u,v)-uv\big)\,du\,dv.$$

For the Gaussian copula take \((X,Y)\) bivariate normal with correlation \(r\). The differences \((X_1-X_2,\,Y_1-Y_2)\) are again bivariate normal with correlation \(r\), and for such a pair the probability that both have the same sign is \(\tfrac12+\tfrac1\pi\arcsin r\) (Sheppard, 1899). So \(\tau=2\big(\tfrac12+\tfrac1\pi\arcsin r\big)-1=\tfrac2\pi\arcsin r\). The formula for \(\rho_S\) follows in the same way from the correlation of \(\Phi(X)\) and \(\Phi(Y)\). \(\square\)

spot check 17.6

A Gaussian copula has correlation parameter \(r=0.5\). What is its Kendall's \(\tau\)? (Three decimals.)

Use \(\tau=(2/\pi)\arcsin r\), and \(\arcsin\tfrac12=\pi/6\).
\(\tau=(2/\pi)(\pi/6)=1/3\approx0.333\). Kendall's tau is smaller than the correlation parameter, as it is for any \(0\lt r\lt1\).

Rank correlations summarise the whole copula. Risk depends on its corners: the probability that both variables are extreme together, as the probability of the event shrinks.

definition 17.9 — tail dependence

The lower and upper tail-dependence coefficients of a bivariate copula are the limits, when they exist,

$$\lambda_L=\lim_{q\to0}P\big(V\le q\mid U\le q\big)=\lim_{q\to0}\frac{C(q,q)}q,$$ $$\lambda_U=\lim_{q\to1}P\big(V\gt q\mid U\gt q\big)=\lim_{q\to1}\frac{1-2q+C(q,q)}{1-q}.$$

A copula with \(\lambda_L\gt0\) makes joint extremes in the lower tail stay likely however extreme the threshold; with \(\lambda_L=0\) they become, relative to one extreme, ever rarer.

proposition 17.11 — tail dependence of common copulas

For the Gaussian copula with \(r\lt1\), \(\lambda_L=\lambda_U=0\). For the \(t\) copula with correlation \(r\) and \(\nu\) degrees of freedom,

$$\lambda_L=\lambda_U=2\,t_{\nu+1}\!\left(-\sqrt{\frac{(\nu+1)(1-r)}{1+r}}\right),$$

where \(t_{\nu+1}\) is the Student \(t\) distribution function. The Clayton copula (Definition 17.10) has \(\lambda_L=2^{-1/\theta}\) and \(\lambda_U=0\); the Gumbel copula has \(\lambda_L=0\) and \(\lambda_U=2-2^{1/\theta}\); the Frank copula has neither.

For Clayton, \(C(q,q)=(2q^{-\theta}-1)^{-1/\theta}\), so

$$\frac{C(q,q)}q=\big(2-q^{\theta}\big)^{-1/\theta}\to2^{-1/\theta}\qquad(q\to0).$$

For Gumbel, \(C(q,q)=\exp\!\big(-(2(-\ln q)^\theta)^{1/\theta}\big)=q^{2^{1/\theta}}\). Writing \(a=2^{1/\theta}\), l'Hôpital's rule gives

$$\lambda_U=\lim_{q\to1}\frac{1-2q+q^{a}}{1-q}=\lim_{q\to1}\frac{-2+a\,q^{a-1}}{-1}=2-a.$$

The Gaussian and \(t\) results need the asymptotics of the bivariate normal and \(t\) distributions; see McNeil, Frey and Embrechts (2015, section 7.2.4). \(\square\)

4 — Copula families, fitting, and joint crashes

Two kinds of parametric copula cover most applications. Elliptical copulas are taken from elliptical distributions by Sklar's theorem: the Gaussian copula from the multivariate normal, the \(t\) copula from the multivariate \(t\). They extend to any dimension with a correlation matrix as parameter, and the \(t\) copula adds one parameter, \(\nu\), that controls joint extremes in both tails symmetrically. Archimedean copulas are built from a single function.

definition 17.10 — Archimedean copulas

Let \(\varphi:[0,1]\to[0,\infty]\) be continuous, strictly decreasing and convex with \(\varphi(1)=0\). The Archimedean copula with generator \(\varphi\) is

$$C(u,v)=\varphi^{-1}\big(\varphi(u)+\varphi(v)\big).$$

(For a generator with \(\varphi(0)\lt\infty\), \(\varphi^{-1}\) is replaced by the pseudo-inverse, equal to \(\varphi^{-1}\) on \([0,\varphi(0)]\) and to 0 beyond; the three families below have \(\varphi(0)=\infty\).) Three standard choices, each with one parameter \(\theta\):

  • Clayton, \(\theta\gt0\): \(\varphi(t)=(t^{-\theta}-1)/\theta\), so that $$C(u,v)=\big(u^{-\theta}+v^{-\theta}-1\big)^{-1/\theta},\qquad\tau=\frac{\theta}{\theta+2};$$ dependence in the lower tail.
  • Gumbel, \(\theta\ge1\): \(\varphi(t)=(-\ln t)^\theta\), so that $$C(u,v)=\exp\!\Big(-\big[(-\ln u)^\theta+(-\ln v)^\theta\big]^{1/\theta}\Big),\qquad\tau=1-\frac1\theta;$$ dependence in the upper tail.
  • Frank, \(\theta\ne0\): symmetric, with no tail dependence, and generator $$\varphi(t)=-\ln\frac{e^{-\theta t}-1}{e^{-\theta}-1}.$$

Rotating a copula by 180 degrees, \((U,V)\mapsto(1-U,1-V)\), swaps its tails: the survival Gumbel copula has dependence in the lower tail.

How should a copula be fitted when the margins are unknown? The density factorisation of Sklar's theorem suggests fitting the margins first and then the copula to the transformed data, but a wrong margin then contaminates the copula. Replacing the margins by ranks avoids that.

definition 17.11 — maximum pseudo-likelihood

Given pseudo-observations \((\hat U_i,\hat V_i)\), the maximum pseudo-likelihood estimate of a copula parameter \(\theta\) is

$$\hat\theta=\arg\max_\theta\sum_{i=1}^n\log c\big(\hat U_i,\hat V_i;\theta\big).$$

It needs no model for the margins, and it is consistent and asymptotically normal (Genest, Ghoudi and Rivest, 1995). Families with different numbers of parameters are compared by AIC, \(2k-2\log L\), as in Lecture 17a.

history — from Fréchet's question to "the formula that killed Wall Street"

Wassily Hoeffding (1940) and Maurice Fréchet (1951) studied joint distributions with given margins and found the bounds of Theorem 17.8. Answering Fréchet's question of which joint distributions are possible, Abe Sklar (1959) proved the theorem that bears his name and coined the word "copula", Latin for a link or bond. For forty years copulas were mostly a topic in probability theory, until Paul Embrechts, Alexander McNeil and Daniel Straumann (1999, published 2002) showed risk managers how badly correlation can mislead them outside the normal world. In 2000 David X. Li proposed using a Gaussian copula to model the joint default times of companies, and the method became the industry standard for pricing collateralised debt obligations: a single correlation parameter summarised the dependence of hundreds of mortgages or loans. The Gaussian copula has no tail dependence (Proposition 17.11), so it treated simultaneous defaults as far rarer than they turned out to be in 2007–2008. Felix Salmon's 2009 article in Wired called it "the formula that killed Wall Street"; the model did not cause the crisis, but its users had relied on one number to describe a dependence that lived in the tails.

big picture — where copulas are used

Banks and insurers use copulas to combine the risks of business lines, assets or perils into one loss distribution, in capital models built for regulators. Hydrologists use them for floods, where the peak flow, the volume and the duration of a flood are dependent and the design of a dam depends on their joint extremes. In machine learning, Gaussian copulas generate synthetic tabular data (Section 5), model high-dimensional forecasts (Salinas et al., 2019, use a low-rank Gaussian copula process for thousands of related time series), estimate graphical models robustly (Section 6), and estimate mutual information, which equals the negative entropy of the copula (Ma and Sun, 2011). For many variables, vine copulas build a \(d\)-dimensional copula from \(d(d-1)/2\) bivariate ones arranged on a sequence of trees (Bedford and Cooke, 2002; Aas et al., 2009), which allows different tail behaviour for different pairs.

5 — Copulas in machine learning I: synthetic tabular data

Organisations often want to share data they cannot share: patient records, tax returns, customer histories. One response is to release synthetic data, records drawn from a model fitted to the real ones, which should be useful for analysis and model building while matching no real person. Sklar's theorem gives the simplest such model: keep each column's own distribution exactly, and glue the columns together with a Gaussian copula. This was the original model of the Synthetic Data Vault (Patki, Wedge and Veeramachaneni, 2016), and it is a standard baseline in later benchmarks of deep generative models for tables, such as CTGAN (Xu et al., 2019).

definition 17.12 — the Gaussian copula synthesiser

Given a table with \(n\) rows and \(d\) columns:

  1. replace each column by its pseudo-observations \(\hat U_{ij}\) and these by normal scores \(Z_{ij}=\Phi^{-1}(\hat U_{ij})\);
  2. estimate the correlation matrix \(\hat R\) of the normal scores;
  3. draw \(Z^*\sim\mathcal N(0,\hat R)\), set \(U^*_j=\Phi(Z^*_j)\), and map each \(U^*_j\) back through column \(j\)'s empirical quantile function (Theorem 17.6).

Each synthetic column then has the real column's distribution, and pairs of columns have, approximately, the real Spearman correlations.

The usual test of synthetic data is train on synthetic, test on real: fit a model to the synthetic records and measure its error on real held-out records. We use the California housing data of Lectures 3 and 8.

6 — Copulas in machine learning II: the nonparanormal

Lecture 20a will estimate the conditional-independence graph of many variables with the graphical lasso, which assumes multivariate normal data. Real variables are skewed, bounded or heavy-tailed, and a monotone transformation that would make them normal is unknown. A Gaussian copula with arbitrary margins is exactly the model that is normal "up to unknown monotone transformations".

definition 17.13 — the nonparanormal (Liu, Lafferty and Wasserman, 2009)

A random vector \(X\in\mathbb R^d\) follows a nonparanormal distribution, \(X\sim\mathrm{NPN}(\Sigma,f)\), if there are strictly increasing functions \(f_1,\dots,f_d\) such that

$$\big(f_1(X_1),\dots,f_d(X_d)\big)\sim\mathcal N(0,\Sigma),\qquad\Sigma_{jj}=1.$$

Equivalently, \(X\) has a Gaussian copula with correlation matrix \(\Sigma\) and arbitrary continuous margins.

proposition 17.12 — the graph and the correlations from ranks

If \(X\sim\mathrm{NPN}(\Sigma,f)\), then \(X_j\) and \(X_k\) are conditionally independent given the other variables exactly when \((\Sigma^{-1})_{jk}=0\), and \(\Sigma\) is determined by the rank correlations:

$$\Sigma_{jk}=\sin\Big(\frac\pi2\,\tau_{jk}\Big)=2\sin\Big(\frac\pi6\,\rho_{S,jk}\Big).$$

Each \(f_j\) is invertible, so conditioning on \(X_k\) is the same as conditioning on \(f_k(X_k)\), and conditional independence of the \(X_j\) is conditional independence of the \(f_j(X_j)\). For a multivariate normal vector the latter holds exactly when the corresponding entry of the precision matrix is zero (Lecture 20a). The rank correlations of \(X\) are those of \(f(X)\) (Proposition 17.9), and for a normal vector Proposition 17.10 gives \(\tau=\tfrac2\pi\arcsin\Sigma_{jk}\) and \(\rho_S=\tfrac6\pi\arcsin(\Sigma_{jk}/2)\); inverting gives the formulas. \(\square\)

So the graphical lasso can be run on a correlation matrix estimated from ranks, either the correlation of the normal scores \(\Phi^{-1}(\hat U_{ij})\) or Kendall's \(\tau\) mapped through \(\sin(\pi\tau/2)\) (the SKEPTIC estimator of Liu et al., 2012). We test both on a known graph, observed through unknown distortions.

print(f"  nonparanormal, normal-score correlations:                             {best_f1(normal_scores(Xd)):.3f}")

On the undistorted Gaussian data the graphical lasso recovers the 36 edges with an F1 of 0.958 at its best penalty. After the distortions, Pearson correlations mislead it, and the best F1 drops to 0.784. Both nonparanormal estimators recover 0.958, the same as with the undistorted data. The invariance is exact: ranks are unchanged by increasing transformations, so the rank-based matrices are the same whether computed from the distorted or the undistorted data. That they also match the Pearson ideal to three decimals reflects how coarse F1 is on 36 edges. The comparison is generous to all methods, since each is scored at its own best penalty, and it is one simulated graph; but the conclusion, that a rank-based estimate costs almost nothing when the data are Gaussian and protects against distortions when they are not, matches Liu et al.'s theory and experiments.

Bayes — a copula likelihood that uses only ranks

A Bayesian treatment of a copula with unknown margins seems to need priors for the margins too. Hoff (2007) avoids them with the extended rank likelihood: the observed data imply only that the latent normal scores \(Z_{ij}\) are in the same order as the \(X_{ij}\) within each column, and the likelihood of the correlation matrix is the probability of that ordering. A Gibbs sampler alternates between drawing the latent scores, each constrained to an interval set by its neighbours in rank, and drawing the correlation matrix from its conditional posterior. The margins never need to be modelled, and the method works for ordinal and mixed discrete–continuous data, where ranks have ties; it is widely used for imputing missing values in surveys.

causal — independence lives in the copula

Whether \(X\) and \(Y\) are independent, or conditionally independent given \(Z\), is a property of the copula alone: independence means \(C=\Pi\). Constraint-based causal discovery, such as the PC algorithm of Lecture 20b, uses only such statements, so it can run on rank-based tests that are valid for any continuous margins; Harris and Drton (2013) proved that PC with Kendall or Spearman correlations recovers the Markov equivalence class of a nonparanormal model consistently, even in high dimensions. The methods that go beyond equivalence classes, such as LiNGAM or additive-noise models, need more than the copula: they rely on the shapes of the distributions, which the copula has deliberately thrown away.

7 — Summary, exercises, projects, reading

summary
  • Correlation measures linear association and changes under changes of units; very different dependence structures share the same correlation. Five copulas with the same Kendall's tau of 0.5 give conditional joint-crash probabilities from 0.051 to 0.701 at the 1% level.
  • The probability integral transform makes any continuous variable uniform (Theorem 17.6). Sklar's theorem writes every joint distribution as margins glued by a copula, unique for continuous margins (Theorem 17.7); all copulas lie between the Fréchet–Hoeffding bounds (Theorem 17.8), and copulas ignore increasing transformations (Proposition 17.9). Daily industry returns have excess kurtosis of 4.0–5.6; ranks are uniform by construction and unchanged by cubing a series, while Pearson's r falls from 0.584 to 0.357.
  • Kendall's tau and Spearman's rho are functionals of the copula (Proposition 17.10); tail-dependence coefficients describe joint extremes (Definition 17.9). Gaussian and Frank copulas have none, the \(t\) copula has it in both tails, Clayton in the lower and Gumbel in the upper (Proposition 17.11).
  • Copulas are fitted to ranks by maximum pseudo-likelihood and compared by AIC (Definition 17.11). On Fin and BusEq, the t copula (ν = 3.5) has the best AIC and test likelihood; for joint 1% crashes in 2007–2026 the data show 49%, the Gaussian copula predicts 18% and the t copula 38%.
  • The Gaussian copula synthesiser keeps margins and rank correlations but not complex shapes. Gaussian-copula synthetic housing data give a test RMSE of 0.672 (real data 0.452, independent margins 1.159) and put 39% of districts away from real ones.
  • The nonparanormal is a Gaussian copula with unknown margins; its graph is read from rank correlations (Proposition 17.12). After monotone distortions, graphical lasso on Pearson correlations reaches an F1 of 0.784; the nonparanormal keeps the undistorted 0.958.

exercises
  1. Show that the Farlie–Gumbel–Morgenstern family \(C_\theta(u,v)=uv\big(1+\theta(1-u)(1-v)\big)\), \(|\theta|\le1\), consists of copulas with uniform margins, and compute its Spearman's rho and Kendall's tau. What do the answers say about the strength of dependence this family can represent?

    \(C_\theta(u,1)=u\) and \(C_\theta(1,v)=v\), and the density \(c=1+\theta(1-2u)(1-2v)\ge0\) when \(|\theta|\le1\). By Proposition 17.10,

    $$\rho_S=12\int_0^1\!\!\int_0^1\theta\,uv(1-u)(1-v)\,du\,dv=12\theta\Big(\frac16\Big)^2=\frac\theta3,$$

    and a similar calculation gives \(\tau=2\theta/9\). So \(|\rho_S|\le1/3\) and \(|\tau|\le2/9\): the family can only represent weak dependence, which is why it is used for perturbation arguments rather than for data.

  2. Let \((X,Y)\) have standard normal margins and a Clayton copula with \(\theta=2\). Is \((X,Y)\) bivariate normal? Explain using a property from this lecture.

    No. A bivariate normal distribution has a Gaussian copula, which by Sklar's theorem is the only copula giving that joint distribution with normal margins. The Clayton copula has lower tail dependence \(2^{-1/2}\approx0.71\) (Proposition 17.11) while every Gaussian copula with \(r\lt1\) has none. Normal margins are not enough for joint normality.

  3. Using Proposition 17.10, what Kendall's \(\tau\) corresponds to a Gaussian copula with \(r=0.9\), and what Spearman's \(\rho\)? Compare both with \(r\).

    \(\tau=\tfrac2\pi\arcsin0.9\approx0.713\) and \(\rho_S=\tfrac6\pi\arcsin0.45\approx0.891\). Spearman's rho is always close to the Pearson correlation under a Gaussian copula (within about 0.02), while Kendall's tau is noticeably smaller; the measures are on different scales and should not be compared across one another.

  4. For the \(t\) copula with \(r=0.6\), compute \(\lambda\) for \(\nu=4\) and \(\nu=30\) (you may use software for \(t_{\nu+1}\)). What happens as \(\nu\to\infty\)?

    \(\lambda=2t_5\big(-\sqrt{5\cdot0.4/1.6}\big)=2t_5(-1.118)\approx0.31\) for \(\nu=4\), and \(2t_{31}\big(-\sqrt{31\cdot0.4/1.6}\big)=2t_{31}(-2.78)\approx0.009\) for \(\nu=30\). As \(\nu\to\infty\) the \(t\) copula tends to the Gaussian copula and \(\lambda\to0\): heavy tails need small degrees of freedom.

  5. (Code.) Refit the \(t\) copula of Section 4 in rolling five-year windows from 1990 to 2026. Plot the fitted correlation and \(\nu\) over time. When do they change, and what does that imply for a risk model fitted once?

    Use the pseudo-observations within each window and the profile-likelihood fit of the code box. Expect dependence to rise in crises (for example 2000–2002, 2008–2009 and 2020), with the fitted correlation increasing and \(\nu\) tending to fall, so that joint extremes become more likely exactly when they matter; the test-period rise in Kendall's \(\tau\) in Section 4 points the same way. A model fitted on calm years under-predicts joint losses in the next crisis, as the test-period table showed; practice uses time-varying copulas or margins filtered by volatility models (GARCH) and refits frequently.

  6. (Code.) Replace the Gaussian copula in the synthesiser of Section 5 by a Gaussian mixture fitted to the normal scores (Lecture 17a), with 10 components. Does the share of districts on land, and the train-on-synthetic RMSE, improve?

    A Gaussian mixture in normal-score space is no longer a Gaussian copula, and it can bend around the coastline and concentrate on the cities; to keep the real margins, map each synthetic coordinate through the mixture's own marginal distribution function before the empirical quantile function. Expect the share of synthetic districts near real ones and the TSTR error both to move towards the real-data values, with more components helping until the mixture starts to memorise the training rows, which the distance-to-closest-record check will reveal.
