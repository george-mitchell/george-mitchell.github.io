This page learns the policy itself: a network that outputs a probability for each action, or the parameters of a distribution over continuous actions, adjusted directly to increase the expected return. It then adds the ideas that make modern deep RL work: small, safe policy steps; entropy for exploration; search with a model; and learning from a fixed data set without interacting at all.

By the end you should be able to prove the policy gradient theorem and explain why baselines reduce variance without adding bias; derive GAE; prove the performance difference lemma and explain PPO's clipped objective; derive the softmax form of the maximum-entropy policy; explain how MCTS, AlphaZero and MuZero plan; and say why offline RL needs conservatism.

1 — Why optimise policies directly

Value-based methods choose \(\arg\max_aQ(s,a)\). That is easy with a handful of actions and hard when actions are continuous (the torque of a robot joint, the steering angle of a car): every decision becomes an optimisation problem. A parametrised policy \(\pi_\theta(a\mid s)\) outputs actions directly, for example the mean and standard deviation of a Gaussian. It can also represent genuinely random behaviour, which is optimal in games such as rock–paper–scissors and useful whenever the state is only partly observed. And a small change in \(\theta\) changes the policy smoothly, whereas a small change in \(Q\) can flip the greedy action.

2 — The policy gradient theorem, REINFORCE and baselines

definition 22.1 — the policy objective

For an episodic task, let \(\tau=(s_0,a_0,r_1,s_1,a_1,\dots)\) be a trajectory generated by following \(\pi_\theta\). The objective is the expected return,

$$J(\theta)=\mathbb E_{\tau\sim\pi_\theta}\big[G_0\big],\qquad G_t=\sum_{k\ge0}\gamma^kr_{t+k+1}.$$
theorem 22.1 — the policy gradient theorem (likelihood-ratio form)

The gradient of the objective is an expectation over trajectories of the policy's own score function, weighted by the return that follows each action:

$$\nabla_\theta J(\theta)=\mathbb E_{\tau\sim\pi_\theta}\Big[\sum_{t\ge0}\gamma^t\,G_t\,\nabla_\theta\log\pi_\theta(a_t\mid s_t)\Big].$$

The environment's transition probabilities do not appear, so the gradient can be estimated from sampled episodes alone.

Write \(p_\theta(\tau)\) for the probability of a trajectory and \(R(\tau)=G_0\). Using \(\nabla p=p\,\nabla\log p\),

$$\nabla_\theta J=\nabla_\theta\int p_\theta(\tau)R(\tau)\,d\tau=\mathbb E_\tau\big[R(\tau)\,\nabla_\theta\log p_\theta(\tau)\big].$$

The trajectory probability is a product of the start distribution, the policy and the transitions; only the policy depends on \(\theta\):

$$\log p_\theta(\tau)=\log\rho(s_0)+\sum_t\Big[\log\pi_\theta(a_t\mid s_t)+\log p(s_{t+1}\mid s_t,a_t)\Big],\qquad\nabla_\theta\log p_\theta(\tau)=\sum_t\nabla_\theta\log\pi_\theta(a_t\mid s_t).$$

Finally, a reward received before time \(t\) is independent of the action at time \(t\) given the past, and \(\mathbb E[\nabla\log\pi_\theta(a_t\mid s_t)\mid s_t]=0\) (Theorem 22.2 with \(b=1\)). So those rewards contribute nothing, and only the rewards from \(t\) on remain: \(\sum_{k\ge t}\gamma^kr_{k+1}=\gamma^tG_t\). \(\square\)

REINFORCE (Williams, 1992) estimates this expectation with sampled episodes and takes a gradient step. In practice the factor \(\gamma^t\) is usually dropped, which slightly changes the objective but works well. The update has an intuitive form: make the actions that were followed by a high return more likely, and those followed by a low return less likely.

theorem 22.2 — a state-dependent baseline adds no bias

For any function \(b(s)\) that does not depend on the action,

$$\mathbb E_{a\sim\pi_\theta(\cdot\mid s)}\big[b(s)\,\nabla_\theta\log\pi_\theta(a\mid s)\big]=0 .$$

So \(G_t\) in Theorem 22.1 can be replaced by \(G_t-b(s_t)\) without changing the expected gradient.

Using \(\pi\,\nabla\log\pi=\nabla\pi\) and pulling \(b(s)\) out of the sum over actions,

$$\sum_a\pi_\theta(a\mid s)\,b(s)\,\nabla_\theta\log\pi_\theta(a\mid s)=b(s)\,\nabla_\theta\sum_a\pi_\theta(a\mid s)=b(s)\,\nabla_\theta1=0 .$$

For continuous actions the sum is an integral and the same argument holds. \(\square\)

Why bother? The raw return mixes two things: how good the action was, and how good the situation already was. If every return is large and positive, every sampled action is pushed up, and the signal is the small difference between large pushes. Subtracting a baseline, ideally close to \(v_\pi(s)\), leaves only the part that depends on the action, the advantage. The variance falls; the mean does not move.

# REINFORCE on CartPole, with and without a learned baseline (a one-hidden-layer network in numpy)
import numpy as np, gymnasium as gym, time, warnings; warnings.filterwarnings('ignore')
class Net:
    """x -> tanh(x W1 + b1) -> h W2 + b2, with Adam."""
    def __init__(self, n_in, n_h, n_out, g, out_scale=0.01, lr=0.01):
        self.p = [g.standard_normal((n_in, n_h)) * np.sqrt(1 / n_in), np.zeros(n_h), g.standard_normal((n_h, n_out)) * out_scale, np.zeros(n_out)]
        self.m = [np.zeros_like(x) for x in self.p]; self.v = [np.zeros_like(x) for x in self.p]; self.t = 0; self.lr = lr
    def forward(self, x):
        h = np.tanh(x @ self.p[0] + self.p[1]); return h, h @ self.p[2] + self.p[3]
    def backward(self, x, h, dz):                                   # gradients of a loss whose derivative w.r.t. the output is dz
        dh = dz @ self.p[2].T * (1 - h ** 2); return [x.T @ dh, dh.sum(0), h.T @ dz, dz.sum(0)]
    def step(self, grads):
        self.t += 1
        for i, gr in enumerate(grads):
            self.m[i] = 0.9 * self.m[i] + 0.1 * gr; self.v[i] = 0.999 * self.v[i] + 0.001 * gr ** 2
            self.p[i] -= self.lr * (self.m[i] / (1 - 0.9 ** self.t)) / (np.sqrt(self.v[i] / (1 - 0.999 ** self.t)) + 1e-8)
def softmax(z): e = np.exp(z - z.max(-1, keepdims=True)); return e / e.sum(-1, keepdims=True)
def rollouts(env, pol, n_ep, g, gamma=0.99):
    S, A, G, lens = [], [], [], []
    for _ in range(n_ep):
        s, _ = env.reset(seed=int(g.integers(1 << 30))); rs, done = [], False
        while not done:
            a = int(g.random() < softmax(pol.forward(s)[1])[1]); S.append(s); A.append(a)
            s, r, term, trunc, _ = env.step(a); rs.append(r); done = term or trunc
        ret, acc = np.zeros(len(rs)), 0.0
        for t in range(len(rs) - 1, -1, -1): acc = rs[t] + gamma * acc; ret[t] = acc      # return-to-go G_t
        G.append(ret); lens.append(len(rs))
    return np.array(S), np.array(A), np.concatenate(G), lens
def pg_grads(pol, S, A, adv):
    """Gradient of -mean(adv * log pi(A|S)): the REINFORCE estimate (sign flipped for a minimiser)."""
    h, z = pol.forward(S); dz = softmax(z); dz[np.arange(len(A)), A] -= 1; return pol.backward(S, h, dz * adv[:, None] / len(A))
def reinforce(seed, baseline, iters=150, batch=8):
    env = gym.make('CartPole-v1'); g = np.random.default_rng(seed)
    pol, vf = Net(4, 32, 2, g), Net(4, 32, 1, g, out_scale=1.0); curve = []
    for it in range(iters):
        S, A, G, lens = rollouts(env, pol, batch, g); curve.append(np.mean(lens))
        if baseline:
            h, v = vf.forward(S); adv = G - v[:, 0]                  # subtract b(s): the critic's prediction of the return
            for _ in range(5): h, v = vf.forward(S); vf.step(vf.backward(S, h, 2 * (v - G[:, None]) / len(G)))
        else: adv = G
        pol.step(pg_grads(pol, S, A, adv))
    return np.array(curve)

3 — Actor–critic and generalised advantage estimation

An actor–critic method keeps two networks: the actor \(\pi_\theta\) and a critic \(V_\phi(s)\approx v_\pi(s)\) that serves as the baseline. The weight on \(\nabla\log\pi\) is then an estimate of the advantage \(A_\pi(s,a)=q_\pi(s,a)-v_\pi(s)\). Which estimate to use is the bias–variance question of Lecture 21b once more. The one-step estimate is the TD error

$$\delta_t=r_{t+1}+\gamma V_\phi(s_{t+1})-V_\phi(s_t),$$

low in variance but biased if \(V_\phi\) is wrong. The Monte Carlo estimate \(G_t-V_\phi(s_t)\) is unbiased but noisy.

definition 22.2 — generalised advantage estimation (Schulman et al., 2016)

For \(0\le\lambda\le1\), the GAE estimate is an exponentially weighted sum of future TD errors:

$$\hat A_t^{\mathrm{GAE}(\gamma,\lambda)}=\sum_{l\ge0}(\gamma\lambda)^l\,\delta_{t+l}.$$

\(\lambda=0\) gives the TD error \(\delta_t\); \(\lambda=1\) gives \(G_t-V_\phi(s_t)\), the Monte Carlo advantage.

proposition 22.3 — GAE averages the k-step advantage estimates

Let

$$\begin{aligned}\hat A_t^{(k)}&=r_{t+1}+\gamma r_{t+2}+\cdots+\gamma^{k-1}r_{t+k}\\ &\quad+\gamma^kV_\phi(s_{t+k})-V_\phi(s_t)\end{aligned}$$

be the \(k\)-step estimate. Then

$$\hat A_t^{(k)}=\sum_{l=0}^{k-1}\gamma^l\delta_{t+l},\qquad\hat A_t^{\mathrm{GAE}}=(1-\lambda)\sum_{k\ge1}\lambda^{k-1}\hat A_t^{(k)} .$$

In \(\sum_{l\lt k}\gamma^l\delta_{t+l}\) the value terms telescope: each \(+\gamma^{l+1}V(s_{t+l+1})\) cancels the \(-\gamma^{l+1}V(s_{t+l+1})\) of the next term, leaving the rewards, \(\gamma^kV(s_{t+k})\) and \(-V(s_t)\). That is \(\hat A_t^{(k)}\).

Substitute this into the weighted sum and collect the coefficient of each \(\delta_{t+l}\). It appears in every \(\hat A_t^{(k)}\) with \(k>l\), with weight

$$(1-\lambda)\sum_{k>l}\lambda^{k-1}\gamma^l=\gamma^l\lambda^l .$$

This is the GAE coefficient. Small \(\lambda\) trusts the critic (bias); large \(\lambda\) trusts the rewards (variance). \(\square\)

4 — Trust regions: TRPO and PPO

A policy-gradient step is only accurate close to the current policy: the gradient was estimated with data from \(\pi_{\text{old}}\). A step that is too large can collapse performance, and with it the quality of the next batch of data. The following identity says exactly how a new policy's return relates to the old one's.

theorem 22.4 — the performance difference lemma (Kakade and Langford, 2002)

For any two policies \(\pi\) and \(\pi'\) in a discounted MDP with start distribution \(\rho\),

$$J(\pi')-J(\pi)=\frac1{1-\gamma}\;\mathbb E_{s\sim d^{\pi'}}\,\mathbb E_{a\sim\pi'(\cdot\mid s)}\big[A_\pi(s,a)\big],$$

where \(d^{\pi'}(s)=(1-\gamma)\sum_t\gamma^t\Pr(s_t=s\mid\pi')\) is the discounted state distribution of the new policy.

Follow \(\pi'\) from \(s_0\sim\rho\). Since \(A_\pi(s_t,a_t)=\mathbb E[r_{t+1}+\gamma v_\pi(s_{t+1})-v_\pi(s_t)\mid s_t,a_t]\), the sum telescopes:

$$\mathbb E_{\pi'}\Big[\sum_t\gamma^tA_\pi(s_t,a_t)\Big]=\mathbb E_{\pi'}\Big[\sum_t\gamma^tr_{t+1}\Big]+\mathbb E_{\pi'}\Big[\sum_t\big(\gamma^{t+1}v_\pi(s_{t+1})-\gamma^tv_\pi(s_t)\big)\Big]=J(\pi')-\mathbb E_{\rho}\big[v_\pi(s_0)\big].$$

The last term is \(J(\pi)\). Rewriting the left side with the discounted state distribution gives the factor \(1/(1-\gamma)\). \(\square\)

The trouble is that \(d^{\pi'}\) is the state distribution of the policy we have not yet run. Replacing it by the old policy's \(d^{\pi}\) gives a surrogate objective \(L_\pi(\pi')\) that can be estimated from old data with importance weights. It is accurate only if the two policies are close.

theorem 22.5 — the monotonic-improvement bound behind TRPO (Schulman et al., 2015)

With \(\varepsilon=\max_{s,a}|A_\pi(s,a)|\) and \(D^{\max}_{\mathrm{KL}}=\max_s\mathrm{KL}\big(\pi(\cdot\mid s)\,\Vert\,\pi'(\cdot\mid s)\big)\),

$$J(\pi')\;\ge\;L_\pi(\pi')-\frac{4\varepsilon\gamma}{(1-\gamma)^2}\,D^{\max}_{\mathrm{KL}}(\pi,\pi').$$

(Statement.) Maximising the right-hand side can never make the policy worse. TRPO replaces the penalty by a constraint on the average KL divergence and solves it approximately with conjugate gradients.

definition 22.3 — PPO's clipped objective (Schulman et al., 2017)

Let \(r_t(\theta)=\pi_\theta(a_t\mid s_t)/\pi_{\text{old}}(a_t\mid s_t)\) be the probability ratio and \(\hat A_t\) an advantage estimate. Proximal policy optimisation maximises

$$L^{\mathrm{CLIP}}(\theta)=\mathbb E_t\Big[\min\big(r_t(\theta)\hat A_t,\ \operatorname{clip}(r_t(\theta),1-\epsilon,1+\epsilon)\,\hat A_t\big)\Big]$$

for several epochs of minibatch gradient ascent on the same batch. Once the ratio has moved more than \(\epsilon\) in the helpful direction, the gradient of that sample is zero.

code — PPO with GAE on CartPole: the standard recipe and three ablations 
# PPO with generalised advantage estimation (GAE) on CartPole, in about 50 lines of numpy
def gae(rew, val, done, last_val, gamma=0.99, lam=0.95):
    """A_t = sum_k (gamma lam)^k delta_(t+k), with delta_t = r_t + gamma V(s_(t+1)) - V(s_t), cut at episode ends."""
    adv, acc = np.zeros(len(rew)), 0.0
    for t in range(len(rew) - 1, -1, -1):
        nxt = last_val if t == len(rew) - 1 else val[t + 1]
        delta = rew[t] + gamma * nxt * (1 - done[t]) - val[t]; acc = delta + gamma * lam * (1 - done[t]) * acc; adv[t] = acc
    return adv
def ppo(seed, total=100_000, n_steps=2048, epochs=10, mb=64, clip=0.2, lam=0.95, lr=3e-4, return_policy=False):
    env = gym.make('CartPole-v1'); g = np.random.default_rng(seed); pol, vf = Net(4, 64, 2, g, lr=lr), Net(4, 64, 1, g, out_scale=1.0, lr=1e-3)
    s, _ = env.reset(seed=seed); ep_ret, rets, curve, steps = 0.0, [], [], 0
    while steps < total:
        S, A, R, D, LP = [], [], [], [], []
        for _ in range(n_steps):                                      # 1. collect a batch with the current policy
            p_ = softmax(pol.forward(s)[1]); a = int(g.random() < p_[1]); S.append(s); A.append(a); LP.append(np.log(p_[a]))
            s, r, term, trunc, _ = env.step(a); R.append(r); D.append(float(term or trunc)); ep_ret += r
            if term or trunc: rets.append(ep_ret); ep_ret = 0.0; s, _ = env.reset(seed=int(g.integers(1 << 30)))
        steps += n_steps; S, A, R, D, LP = np.array(S), np.array(A), np.array(R), np.array(D), np.array(LP)
        V = vf.forward(S)[1][:, 0]; adv = gae(R, V, D, vf.forward(s)[1][0], lam=lam); ret = adv + V
        for _ in range(epochs):                                       # 2. several epochs of minibatch updates on the same batch
            for idx in np.array_split(g.permutation(n_steps), n_steps // mb):
                a_ = (adv[idx] - adv[idx].mean()) / (adv[idx].std() + 1e-8); h, z = pol.forward(S[idx]); pr = softmax(z)
                ratio = pr[np.arange(len(idx)), A[idx]] / np.exp(LP[idx])
                active = ~(((ratio > 1 + clip) & (a_ > 0)) | ((ratio < 1 - clip) & (a_ < 0)))   # where the clipped objective has a gradient
                dlogp = -ratio * a_ * active / len(idx)                                       # d loss / d log pi(a|s)
                dz = -pr * dlogp[:, None]; dz[np.arange(len(idx)), A[idx]] += dlogp; pol.step(pol.backward(S[idx], h, dz))
                h, v = vf.forward(S[idx]); vf.step(vf.backward(S[idx], h, 2 * (v - ret[idx, None]) / len(idx)))
        curve.append(np.mean(rets[-20:]) if rets else 0.0)
    return (pol, vf) if return_policy else np.array(curve)
t0 = time.time(); ppo_runs = {}

          f"   (seeds at 100k: {', '.join(f'{x:.0f}' for x in c[:, -1])})")

With the standard settings PPO solves CartPole: the mean return reaches 494 after 50,000 steps and 500, the maximum, after 100,000. Two ablations behave as theory suggests. With \(\lambda=0\) the advantages are one-step TD errors of a critic that starts out wrong, and learning is far slower (334 after 100,000 steps); with \(\lambda=1\) (Monte Carlo advantages) it is a little slower than at 0.95 early on (251 against 296 after 20,000 steps). Removing the clip changes nothing at the standard learning rate (500): the steps are already small. Clipping is insurance against steps that are too large, and on an easy task with careful settings the insurance is not needed.

5 — Maximum-entropy RL and Soft Actor-Critic

An agent that becomes certain too early stops exploring. Maximum-entropy RL rewards the policy for staying random where randomness costs little: it maximises

$$J_\alpha(\pi)=\mathbb E_\pi\Big[\sum_t\gamma^t\big(r_{t+1}+\alpha\,\mathcal H(\pi(\cdot\mid s_t))\big)\Big],\qquad\mathcal H(p)=-\sum_ap(a)\log p(a),$$

where the temperature \(\alpha\) sets the price of certainty. The value functions become "soft": the soft Bellman equation for the optimal policy reads

$$Q(s,a)=r(s,a)+\gamma\,\mathbb E_{s'}\big[V(s')\big],\qquad V(s)=\alpha\log\sum_a\exp\!\big(Q(s,a)/\alpha\big).$$
theorem 22.6 — the maximum-entropy policy is a softmax of the soft Q-function

In each state, the policy that maximises \(\sum_a\pi(a)Q(s,a)+\alpha\mathcal H(\pi)\) is the Boltzmann policy

$$\pi^*(a\mid s)=\frac{\exp\big(Q(s,a)/\alpha\big)}{\sum_{a'}\exp\big(Q(s,a')/\alpha\big)}=\exp\!\Big(\frac{Q(s,a)-V(s)}{\alpha}\Big),$$

and the maximum value is \(V(s)=\alpha\log\sum_a\exp(Q(s,a)/\alpha)\). As \(\alpha\to0\) it becomes the greedy policy.

Write \(q_a=Q(s,a)/\alpha\) and \(\sigma_a=e^{q_a}/\sum_be^{q_b}\). For any distribution \(\pi\),

$$\sum_a\pi(a)q_a-\sum_a\pi(a)\log\pi(a)=\log\sum_be^{q_b}-\sum_a\pi(a)\log\frac{\pi(a)}{\sigma_a}=\log\sum_be^{q_b}-\mathrm{KL}(\pi\,\Vert\,\sigma).$$

The KL divergence is non-negative and zero only at \(\pi=\sigma\). Multiplying by \(\alpha\) gives both claims. \(\square\)

Soft Actor-Critic (SAC; Haarnoja et al., 2018) applies this to continuous actions. Two critics learn the soft Q-function by bootstrapping from slowly moving target copies (the smaller of the two is used, to curb overestimation). The actor, a squashed Gaussian, is trained to minimise \(\mathbb E[\alpha\log\pi(a\mid s)-Q(s,a)]\), the per-state KL divergence of Theorem 22.6 up to a constant. SAC is off-policy, so it reuses a replay buffer, and it is among the most sample-efficient model-free methods for robot control.

def jinit(key, sizes):
    ps = []
    for a, b in zip(sizes[:-1], sizes[1:]): key, k = jax.random.split(key); ps.append((jax.random.normal(k, (a, b)) * jnp.sqrt(1 / a), jnp.zeros(b)))

    for W, b in ps[:-1]: x = jax.nn.relu(x @ W + b)

def actor_sample(pa, s, key):                                     # tanh-squashed Gaussian policy; returns action in [-1, 1] and log-probability

    u = mu + jnp.exp(log_std) * jax.random.normal(key, mu.shape); a = jnp.tanh(u)

bayes — control as inference

Maximum-entropy RL has a probabilistic reading (Levine, 2018). Add to each time step a binary "optimality" variable with \(p(\mathcal O_t=1\mid s_t,a_t)\propto\exp(r_t/\alpha)\), and ask for the posterior over trajectories given that every step was optimal. With a uniform action prior and deterministic dynamics, the exact posterior over actions is the soft-optimal policy of Theorem 22.6. With random dynamics exact inference becomes over-optimistic (it assumes the dice will fall favourably), and the fix is variational inference (Lecture 16b's ELBO) with the policy as the approximate posterior, which recovers maximum-entropy RL. The temperature plays the part of the noise level in the likelihood. Lecture 22b meets the same structure again: a KL-regularised objective whose optimum is the prior reweighted by \(\exp(r/\beta)\).

6 — Planning with search and models

When a model of the environment is available, as in board games, an agent can plan: look ahead before acting. Monte Carlo tree search (MCTS; Coulom, 2006; Kocsis and Szepesvári, 2006) builds a search tree one simulation at a time. Each simulation has four steps:

  1. select: from the root, descend by choosing children that maximise a UCB score, \(\bar w+c\sqrt{\ln N_{\text{parent}}/N_{\text{child}}}\), the bandit rule of Lecture 21a applied at every node;
  2. expand: add one new child;
  3. simulate: play to the end with a fast default policy (in pure MCTS, random moves);
  4. back up: add the result to the visit counts and win totals along the path.

After many simulations, the move with the most visits is played. Promising lines are explored deeply, poor ones only lightly, and no evaluation function is needed.

code — UCT on Connect Four: strength against the number of simulations 
# Monte Carlo tree search (UCT) on Connect Four: playing strength grows with the number of simulations
import math
H1 = 7                                                             # bitboard: 7 columns x (6 rows + 1 sentinel)
TOP = sum(1 << (c * H1 + 5) for c in range(7))
def won(b):
    for d in (1, H1, H1 - 1, H1 + 1):                              # vertical, horizontal, two diagonals
        m = b & (b >> d)
        if m & (m >> 2 * d): return True
    return False
class C4:
    def __init__(s): s.b = [0, 0]; s.h = [c * H1 for c in range(7)]; s.p = 0; s.n = 0
    def moves(s): return [c for c in range(7) if not (1 << s.h[c]) & TOP << 1 and s.h[c] < c * H1 + 6]
    def play(s, c): s.b[s.p] |= 1 << s.h[c]; s.h[c] += 1; s.n += 1; s.p ^= 1
    def copy(s): t = C4(); t.b = s.b[:]; t.h = s.h[:]; t.p = s.p; t.n = s.n; return t
    def winner(s): return 0 if won(s.b[0]) else (1 if won(s.b[1]) else (-1 if s.n == 42 else None))
def rollout(st, g):
    st = st.copy()
    while (w := st.winner()) is None:
        mv = st.moves(); st.play(mv[g.integers(len(mv))])
    return w
def uct_move(st, sims, g, c=1.4):
    """UCT: select by upper confidence bounds, expand one node, simulate randomly to the end, back up the result."""
    root = {'N': 0, 'W': 0.0, 'kids': {}, 'untried': st.moves(), 'player': st.p}
    for _ in range(sims):
        node, s, path = root, st.copy(), [root]
        while not node['untried'] and node['kids'] and s.winner() is None:      # 1. selection
            node = max(node['kids'].values(), key=lambda k: k['W'] / k['N'] + c * math.sqrt(math.log(node['N']) / k['N']))
            s.play(node['move']); path.append(node)
        if node['untried'] and s.winner() is None:                               # 2. expansion
            mv = node['untried'].pop(g.integers(len(node['untried']))); mover = s.p; s.play(mv)
            kid = {'N': 0, 'W': 0.0, 'kids': {}, 'untried': s.moves() if s.winner() is None else [], 'move': mv, 'mover': mover}
            node['kids'][mv] = kid; path.append(kid)
        w = rollout(s, g)                                                       # 3. simulation
        for nd in path:                                                         # 4. backup: reward from the view of the player who moved into nd
            nd['N'] += 1
            if 'mover' in nd: nd['W'] += 1.0 if w == nd['mover'] else (0.5 if w == -1 else 0.0)
    return max(root['kids'].values(), key=lambda k: k['N'])['move']
def match(sims_a, sims_b, games, seed):
    g = np.random.default_rng(seed); score = 0.0
    for k in range(games):
        st = C4(); a_first = k % 2 == 0
        while (w := st.winner()) is None:
            a_turn = (st.p == 0) == a_first; sims = sims_a if a_turn else sims_b
            mv = st.moves(); st.play(mv[g.integers(len(mv))] if sims == 0 else uct_move(st, sims, g))
        a_player = 0 if a_first else 1; score += 1.0 if w == a_player else (0.5 if w == -1 else 0.0)
    return score / games

7 — Offline RL and off-policy evaluation

Often the agent cannot experiment: medical treatments, driving and industrial control come with logs of past behaviour, and new trials are expensive or dangerous. Offline RL learns a policy from a fixed data set collected by some behaviour policy \(\pi_b\). Two questions arise: how good would a new policy be (evaluation), and how to find a good one (control).

theorem 22.7 — importance sampling evaluates a policy without bias

Let trajectories be collected by \(\pi_b\), and let \(\pi\) take an action only where \(\pi_b\) can. With per-step ratios \(\rho_t=\pi(a_t\mid s_t)/\pi_b(a_t\mid s_t)\),

$$\mathbb E_{\tau\sim\pi_b}\Big[\Big(\prod_{t=0}^{T-1}\rho_t\Big)G_0\Big]=\mathbb E_{\tau\sim\pi}\big[G_0\big]=J(\pi).$$

The doubly robust estimator (Jiang and Li, 2016; Thomas and Brunskill, 2016) adds a learned model \(\hat Q\) as a control variate. It is unbiased if the ratios are correct, whatever \(\hat Q\) is, and consistent if \(\hat Q\) is correct, even when the ratios are wrong: two chances to be right. (Second part: statement.)

The probability of a trajectory under a policy is \(\rho(s_0)\prod_t\pi(a_t\mid s_t)p(s_{t+1}\mid s_t,a_t)\). Dividing the two, the start distribution and the transitions cancel:

$$\frac{p_\pi(\tau)}{p_{\pi_b}(\tau)}=\prod_t\frac{\pi(a_t\mid s_t)}{\pi_b(a_t\mid s_t)}=\prod_t\rho_t .$$

Hence \(\mathbb E_{\pi_b}[\prod_t\rho_t\,G_0]=\sum_\tau p_{\pi_b}(\tau)\frac{p_\pi(\tau)}{p_{\pi_b}(\tau)}G_0(\tau)=\mathbb E_\pi[G_0]\). The condition on supports ensures no division by zero where \(p_\pi>0\). \(\square\)

The product of ratios makes the variance grow exponentially with the horizon, which is why importance sampling is used mainly for short horizons and bandits (the ZOZOTOWN example of Lecture 21a). For control, the danger is different. Q-learning on a fixed data set evaluates \(\max_aQ(s',a)\), including actions that never appear in the data. Their values are pure extrapolation, often wildly optimistic, and the greedy policy steers straight towards them, with no new data to correct the mistake. Conservative Q-learning (CQL; Kumar et al., 2020) adds a penalty that pushes down the values of all actions and pushes up those actually in the data:

$$\mathcal L_{\mathrm{CQL}}=\mathcal L_{\mathrm{TD}}+\alpha\,\mathbb E_{s\sim\mathcal D}\Big[\log\sum_a\exp Q(s,a)-\mathbb E_{a\sim\mathcal D}\,Q(s,a)\Big].$$

A different route treats offline RL as supervised sequence modelling: the Decision Transformer (Chen et al., 2021) is a GPT-style model trained to predict the next action given past states, actions and the return still to come; at test time one asks for a high return and lets it act.

CartPole's data set is kind, and it is home-made. Offline RL papers report results on shared benchmarks instead, above all D4RL (Fu et al., 2020), now maintained in the Minari library. The next box takes one of them: a point mass in a U-shaped maze, pushed by a two-dimensional force, rewarded at every step by \(e^{-\text{distance to the goal}}\). The million logged steps come from a controller that follows waypoints to a series of random goals, with noise added to its actions; the test is to reach one fixed goal within 300 steps. Scores are normalised so that 0 is a random policy and 100 is the controller that made the data. Beside behaviour cloning we run TD3 (Fujimoto, van Hoof and Meger, 2018), an off-policy actor–critic for continuous actions (a deterministic actor, twin critics, smoothed targets and actor updates every second step; much like SAC without the entropy), first unconstrained and then with the one-line conservative fix of TD3+BC (Fujimoto and Gu, 2021): the actor maximises \(\lambda Q(s,\pi(s))-(\pi(s)-a)^2\), with \(\lambda=2.5/\overline{|Q|}\), so it is penalised for moving away from the logged action \(a\).

data — D4RL PointMaze U-maze (dense reward), from Minari

13,210 episodes and 1,000,000 transitions collected in PointMaze_UMazeDense-v3 (Gymnasium-Robotics, MuJoCo physics) by a PD controller following waypoints from Q-iteration, with noise on the actions (Fu et al., 2020; Farama Foundation's Minari release D4RL/pointmaze/umaze-dense-v2, from the Hugging Face Hub). Each state is the point's position and velocity plus the goal's position.

@partial(jax.jit, static_argnames=('bc', 'actor'))
def td3_step(P, O, batch, key, bc, actor):
    s, a, r, s2, d = batch; O = dict(O)
    noise = jnp.clip(0.2 * jax.random.normal(key, a.shape), -0.5, 0.5); a2 = jnp.clip(jnp.tanh(jmlp(P['ta'], s2)) + noise, -1, 1)
    sa2 = jnp.concatenate([s2, a2], -1); y = r + 0.99 * (1 - d) * jnp.minimum(jmlp(P['t1'], sa2)[:, 0], jmlp(P['t2'], sa2)[:, 0])
    y = jax.lax.stop_gradient(y); sa = jnp.concatenate([s, a], -1)
    lq = lambda q: jnp.mean((jmlp(q, sa)[:, 0] - y) ** 2)
    def la(pa):                                                  # TD3+BC: maximise lambda Q, lambda = 2.5 / mean|Q|, minus (pi(s) - a)^2
        pi = jnp.tanh(jmlp(pa, s)); q = jmlp(P['q1'], jnp.concatenate([s, pi], -1))[:, 0]
        lam = (2.5 if bc else 1.0) / jax.lax.stop_gradient(jnp.mean(jnp.abs(q)))
        return -lam * jnp.mean(q) + (jnp.mean((pi - a) ** 2) if bc else 0.0)
    new = dict(P)
    for k in ('q1', 'q2'):
        g = jax.grad(lq)(P[k]); new[k], O[k] = jadam_step(P[k], g, O[k])
    if actor:                                                    # TD3: the actor and the targets move every second step
        g = jax.grad(la)(P['a']); new['a'], O['a'] = jadam_step(P['a'], g, O['a'])
        for k, t in (('q1', 't1'), ('q2', 't2'), ('a', 'ta')): new[t] = jax.tree.map(lambda x, y_: 0.995 * x + 0.005 * y_, new[t], new[k])
    return new, O
@jax.jit
def bc_step(pa, O, s, a):
    g = jax.grad(lambda pa: jnp.mean((jnp.tanh(jmlp(pa, s)) - a) ** 2))(pa); return jadam_step(pa, g, O)

def score(pa, q=None, n=30):
    tot, disc, pred = [], [], []
    for i in range(n):
        ob, _ = env5.reset(seed=1000 + i); ret, dret, k, done = 0.0, 0.0, 0, False
        while not done:
            s = nz(np.hstack([ob['observation'], ob['desired_goal']]).astype(np.float32))
            if k == 0 and q is not None: pred.append(float(jmlp(q, jnp.concatenate([s, act(pa, s)]))[0]))   # the critic's forecast at the start
            ob, r, term, trunc, _ = env5.step(np.asarray(act(pa, s))); ret += r; dret += 0.99 ** k * r; k += 1; done = term or trunc
        tot.append(ret); disc.append(dret)
    lo, hi = meta['ref_min_score'], meta['ref_max_score']
    return 100 * (np.mean(tot) - lo) / (hi - lo), np.mean(disc), (np.mean(pred) if pred else None)   # 0 = random, 100 = the controller

Unconstrained TD3 fails outright: it scores −11.7, below a random policy. Its critic is too optimistic about it: at the start of each test episode it forecasts a discounted return of 16.3, and the policy collects 12.6. The actor has steered towards actions the data rarely or never contain, where the critic's values are guesses that no data correct, the extrapolation error that motivated CQL. TD3+BC keeps the actor near the logged actions and scores 54.1; its critic errs the other way, forecasting 5.8 where the policy obtains 36.1. Conservatism bought a safe policy, not an accurate value function: the behaviour-cloning term, not the critic, is doing most of the work. Behaviour cloning alone scores 55.6. On this data set, as on CartPole's, imitation is a strong baseline because the data come from a competent controller; with one seed and 30,000 updates the two differ by less than one would trust from a single run, and both fall short of the controller itself, which planned with a map of the maze. Published D4RL comparisons point the same way: conservative methods win clearly on data sets of mixed or poor quality, and barely on expert data.

causal — offline RL is causal inference with feedback

Evaluating a new policy from logs asks what would have happened under different actions: a counterfactual. Importance weighting is inverse propensity weighting (Lecture 13 and Lecture 21a), and the doubly robust estimator is the same object as in causal effect estimation, with the same double protection. The assumptions are also the same: the logged probabilities must be known, every action the new policy might take must sometimes have been taken (overlap), and nothing that influenced both the logged action and the outcome may be missing from the state (no unmeasured confounding). A doctor who treated sicker patients more aggressively, on the basis of signs not recorded in the data, makes the treatment look harmful in the logs. No amount of offline RL can undo that without extra assumptions or experiments.

quantum — reinforcement learning for quantum devices

RL has become a tool for controlling quantum systems, where accurate models are expensive and every measurement disturbs the state. Bukov et al. (Physical Review X, 2018) used RL to design pulse sequences that prepare target quantum states, and found protocols competitive with optimal control. Fösel, Tighineanu, Weiss and Marquardt (Physical Review X, 2018) trained networks with RL to discover feedback strategies that protect qubits against noise, a form of quantum error correction found without being told the textbook codes. AlphaTensor-Quantum (Ruiz et al., Nature Machine Intelligence, 2025) adapted AlphaZero-style search to reduce the number of costly T gates in quantum circuits. The speed-up here is classical: RL makes quantum hardware better, rather than quantum hardware making RL faster.

big picture — RL beyond games

The same algorithms now act outside games. Policies trained with PPO and SAC in simulation, with randomised physics so that they transfer, control legged robots and robot hands in the real world. Degrave et al. (Nature, 2022) shaped the plasma of the TCV tokamak in Lausanne with an RL controller. AlphaTensor (Fawzi et al., Nature, 2022) found faster matrix-multiplication algorithms for some sizes, and AlphaDev (Mankowitz et al., Nature, 2023) found sorting routines now in the LLVM C++ standard library. RL for chip floorplanning (Mirhoseini et al., Nature, 2021) has been contested: later studies could not reproduce its advantage over established tools, and the debate over evaluation is itself a lesson in the critical reading of Lecture 23. The most widespread use of RL today is in Lecture 22b: shaping the behaviour of language models.

summary
  • The policy gradient is an expectation of return-weighted score functions (Theorem 22.1); baselines remove the part of the return that does not depend on the action, reducing variance without bias (Theorem 22.2). On CartPole, a learned baseline lifts REINFORCE to 491 after 80 updates (without: 402).
  • Actor–critic methods estimate advantages with a learned critic; GAE(λ) averages k-step estimates and sets the bias–variance trade-off (Proposition 22.3).
  • The performance difference lemma (Theorem 22.4) explains why policy steps must stay small; TRPO bounds them (Theorem 22.5) and PPO clips the probability ratio (Definition 22.3). PPO solves CartPole in 100,000 steps; at a tenfold learning rate it still reaches 495 with clipping and only 251 without.
  • Maximum-entropy RL makes the optimal policy a softmax of the soft Q-function (Theorem 22.6); SAC's temperature sets how random it stays. On Pendulum, SAC reaches about −140 for small \(\alpha\), and falls to −1075 when \(\alpha=50\).
  • MCTS plans by sampling; AlphaZero adds a learned policy and value, MuZero a learned model. On Connect Four, UCT with 1600 simulations beats UCT with 400 simulations in 71% of games.
  • Importance sampling evaluates policies offline without bias but with high variance (Theorem 22.7); offline control needs conservatism against extrapolated values. From a fixed CartPole data set, CQL with \(\alpha=5\) scores 500 against 436 for plain offline Q-learning. On the D4RL point-maze benchmark, unconstrained TD3 scores −11.7 while TD3+BC scores 54.1 and behaviour cloning 55.6.
exercises
  1. For a softmax policy \(\pi_\theta(a)=e^{\theta_a}/\sum_be^{\theta_b}\) over \(K\) actions, show that \(\partial\log\pi_\theta(a)/\partial\theta_j=\mathbf 1[a=j]-\pi_\theta(j)\). What is the REINFORCE estimate of \(\partial J/\partial\theta_j\) from one pull of arm \(a\) with reward \(r\)?

    \(\log\pi_\theta(a)=\theta_a-\log\sum_be^{\theta_b}\), whose derivative with respect to \(\theta_j\) is \(\mathbf 1[a=j]-e^{\theta_j}/\sum_be^{\theta_b}\). The estimate is \(r\,(\mathbf 1[a=j]-\pi_\theta(j))\). If every reward is shifted by a constant \(c\), each estimate shifts by \(c\,(\mathbf 1[a=j]-\pi_\theta(j))\), which has mean zero but large variance when \(c\) is large: the effect shown in the variance lab.

  2. What baseline \(b\) (a constant) minimises the variance of the single-sample estimate \((r-b)\,g\), where \(g=\nabla\log\pi(a)\) is a scalar?

    The mean does not depend on \(b\) (Theorem 22.2), so minimise \(\mathbb E[(r-b)^2g^2]\). Setting the derivative to zero gives

    $$b^*=\frac{\mathbb E[r\,g^2]}{\mathbb E[g^2]},$$

    a weighted average of rewards, weighted by \(g^2\). In practice the plain expected reward (or \(v_\pi(s)\)) is used; it is close to optimal and easy to learn.

  3. Show that PPO's objective \(\min(rA,\operatorname{clip}(r,1-\epsilon,1+\epsilon)A)\) equals \(rA\) whenever \(r\in[1-\epsilon,1+\epsilon]\), and that its gradient with respect to \(r\) is zero when \(A>0\) and \(r>1+\epsilon\).

    Inside the interval, clipping does nothing, so both arguments equal \(rA\). For \(A>0\) and \(r>1+\epsilon\), the clipped term is \((1+\epsilon)A\lt rA\), so the minimum is the constant \((1+\epsilon)A\), with zero gradient. The sample no longer pulls the policy further in that direction. If instead the ratio has moved the wrong way (\(r<1-\epsilon\) with \(A>0\)), the minimum is \(rA\) and the full gradient remains: PPO corrects bad moves but limits good ones.

  4. Using Theorem 22.6, write the soft value \(V(s)\) for two actions with \(Q\)-values 1 and 0 at \(\alpha=1\) and \(\alpha=0.1\). What are the policies?

    At \(\alpha=1\): \(V=\log(e+1)\approx1.313\), and \(\pi=(e/(e+1),1/(e+1))\approx(0.731,0.269)\). At \(\alpha=0.1\): \(V=0.1\log(e^{10}+1)\approx1.000\), and \(\pi\approx(0.99995,0.00005)\). A low temperature gives almost the greedy policy and \(V\approx\max_aQ\).

  5. An episode of 50 steps is logged under a behaviour policy that takes each of two actions with probability 0.5; the target policy takes the logged action with probability 0.9 at every step. What is the importance weight of the whole episode? Why is per-decision importance sampling better?

    Each ratio is \(0.9/0.5=1.8\), so the weight is \(1.8^{50}\approx5.8\times10^{12}\). Most episodes, in which the target policy would have chosen differently at some steps, get weights close to zero instead (each such step contributes a factor \(0.1/0.5=0.2\)). The estimate rests on a few astronomically weighted episodes. Per-decision importance sampling weights each reward \(r_{t+1}\) only by the ratios up to time \(t\), since later actions cannot affect it, which reduces the variance; doubly robust estimators reduce it further.

  6. (Code.) Change the CartPole data set to contain only the expert's actions (no random half). Which of the three offline methods benefits most, and why does offline Q-learning become worse when the data contain only one action per state?

    Behaviour cloning becomes nearly perfect: it copies an expert. Offline Q-learning has no examples of the other action at all, so its value comes entirely from the network's extrapolation, and errors there are never corrected. This is the case CQL was designed for: its penalty keeps the unseen action's value below the seen one's, and its policy then stays close to the data. Narrow, expert-only data sets are where conservatism matters most.
